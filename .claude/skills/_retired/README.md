# Retired skills

Peri-op clinical skills. The code they describe is flag-gated for deletion — see
`git tag legacy-periop-final`. Kept for reference only.

A skill that describes dead code is worse than no skill: it triggers on a real
question and sends the agent to edit `pipeline/` or the peri-op scoring modules,
confidently, in a product that no longer sells that.

Do not re-enable without deleting this README and confirming the code is live.
